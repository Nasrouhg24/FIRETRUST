# Submission preparation checklist

- [x] Working local application and native Windows start command.
- [x] Historical NASA data with source hashes and processing provenance.
- [x] Baselines, model selection, held-out tests and uncertainty diagnostics.
- [x] Explicit statement that ground-truth validation is absent.
- [x] Method, limitations, reproduction guide and machine-readable evidence.
- [x] Desktop/mobile screenshots and two-minute demo storyboard.
- [x] AI-use disclosure draft and NASA source attribution.
- [x] Reviewable source/evidence ZIP, generated by `scripts/package_submission.py`.
- [ ] Owner supplies final team names and confirms applicable event requirements.
- [ ] Owner publishes repository/demo if required by the event.
- [ ] Owner records and reviews the final video.
- [ ] Owner submits the entry and checks acknowledgment.

The unchecked items are final external/event actions, not claims of completed publication or submission.
